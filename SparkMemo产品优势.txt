【核心定位】
SparkMemo = 笔记 → 卡片 → 复习 → 反思 的完整学习闭环，
全程本地运行，AI 可选、模型自由、数据自主。

──────────────────────────────
一、相比同类记忆软件（Anki / 墨墨 / 扇贝等）的优势
──────────────────────────────
1. 本地优先，隐私安全
   · 无账号体系、无强制云端、无广告、无学习数据画像
   · 所有数据保存在本机，可随时导出 .db 完整备份、随时恢复

2. 科学调度：FSRS-5 间隔重复算法
   · 比传统 SM-2 更精确的下一代算法（预期记忆保持率可调）
   · 每日新卡上限 1-99999999 任意设置，留空即不限
   · 复习目标 / 每日计划 / 学习时长目标均可自定义

3. AI 全链路（可选配置，不强制）
   · AI 制卡：按章节内容量自动生成，内容多则多生成，
     多轮并行 + 失败自动重试，超大文档自动分块不超上下文
   · AI 出题：单选/多选/填空/简答，数量自定义或 AI 自决
   · AI 反思：每日草稿（基础统计 / 专业 AI 分析）+ 周度学习分析
   · AI 计划：依据一周真实学习数据自动调整下周计划
   · AI 助手：对话即操作——加卡片 / 查统计 / 改设置 / 看计划
   · AI 定制：一句话改主题色 / 字体 / 深色模式 / 背景图

4. 模型自由，成本可控
   · 兼容 DeepSeek / OpenAI / Kimi / GLM / Claude / Ollama（本地）
   · 可用免费或低价档模型，按实际调用计费，无软件订阅费
   · API Key 本地混淆存储，不上传任何第三方

5. 学习不设上限
   · AI 制卡 / 出题数量由内容决定，无固定上限
   · 笔记导入格式全（md/txt/csv/docx/pptx/xlsx/pdf）

6. 双平台一致体验
   · Windows 绿色免安装 + Android APK
   · 局域网增量同步（时间戳冲突处理），手机电脑数据互通

7. 数据自主
   · 导出 Excel / PDF / 数据库级备份，格式开放、随时迁移
   · 无锁定、无订阅陷阱

──────────────────────────────
二、工程与安全（正式版加固说明）
──────────────────────────────
· Release AOT 编译：Dart 代码编译为机器码快照，
  安装包内不含任何 .dart 源码
· Dart 符号混淆（--obfuscate）：类名 / 函数名 / 变量名不可读
· Android R8 代码混淆 + 代码收缩
· 符号表（symbols）仅本地保留用于故障还原，不随安装包分发
· 安装包仅含运行所需产物，不含工程文件 / 中间构建物 / 调试信息
· 说明：以上加固可显著提高逆向与源码还原门槛；
  字符串等资源受平台限制为明文，但业务逻辑与符号结构不可直接阅读

──────────────────────────────
三、适用人群
──────────────────────────────
· 考研 / 考公 / 考证：知识点卡片 + 科学复习调度
· 语言学习：单词 / 语法卡片，AI 出题自测，AI 制卡省时
· 课程 / 网课学习：笔记自动转卡片，AI 总结浓缩要点
· 隐私敏感用户：数据绝不出本机，AI 可完全使用本地模型（Ollama）

SparkMemo —— 把「记住」这件事，交给算法与 AI。
