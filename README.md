# SparkMemo 智能记忆学习助手

> 本地优先 · FSRS-6 · 理工科智能学习 · Windows + Android

把「笔记 → 卡片 → 作答 → 复习 → 反思」连接成学习闭环。学习数据保存在本机 SQLite，无需注册 SparkMemo 账号，无广告。基础学习功能可离线使用；使用云端 AI 时，相关内容会发送给所配置的服务。

**v2.3.3 制卡、难度与综合出题优化版**：396 项测试通过，静态检查 0 error、13 warning、99 info。AI 制卡按带原文证据的知识清单分批生成、补齐遗漏；题目难度支持 6、10、12 及更高等级，超难题保留完整，不强拆、不压成 5；适当结合相关知识点并保留主次知识点信息。Windows 启动检查通过；加固 APK 已于 2026-09-18 在 Android 16 真机覆盖安装成功，公开包冷启动待补验，不沿用开发版的结果。详见 [v2.3.3 发布说明与 SHA-256](https://github.com/sjjeh1002/SparkMemo/releases/tag/v2.3.3)。AI 清单覆盖和语义难度仍需人工核对，测试通过不代表模型永不出错。

- **FSRS-6 科学复习：**21 参数，默认保持率 90%；支持同日短期复习、每日新卡上限、到期队列与四档评分。
- **理工科智能学习：**区分记忆/推理知识点，支持 10 种题型、可扩展正整数难度（含 6 级以上）、提示、错误诊断、变式练习和独立知识点掌握度。题目等级与 FSRS 记忆难度独立。

## 加固与限制

公开版采用 Release AOT、Dart 混淆；Android 额外执行 R8、原生库符号剥离、FixApk（arsc/lib STORED+CRC）、16KB zipalign 和 v2/v3 签名校验。调试符号仅留本机。

这些处理不等于不可逆安全保证或商业加壳。开放题 AI 判断可能出错；不含代码执行沙箱或 FSRS 权重训练器；高阶变式依赖 AI/已有题库。知识点掌握度及作答历史目前不跨设备合并。不同版本可能使用同一数据库，降级前需要兼容备份。

## 快速使用

1. Windows 解压公开版运行；Android 备份数据后安装公开版 APK，建议先用少量卡片确认本机兼容性。
2. 在首页体验内置训练，或导入笔记、添加卡片。
3. AI 可选：Windows 在「设置 → AI 模型配置」选择 Codex 并登录 ChatGPT；其他服务按需配置地址、密钥与模型。
4. 使用「开始今天的学习」作答；需要传统翻卡评分时，在设置开启手动 FSRS。
5. 定期备份本地数据库。

### 图片与扫描教材导入

在「笔记」右上角选择「图片 / PDF 识图导入」，可一次多选 PNG/JPEG/WebP 或 PDF；每批最多 1000 页，单图 20 MB、PDF 500 MB。先在本地保存原页，可暂停、重新选原文件续导，不会重复保存成功页。配置独立识图 API 后，点击识别并确认发送；逐页核对公式、文字和图像，再创建笔记。

普通文档入口选择 PDF 后，可选「保留图片 / 识图导入」或「仅文字（离线）」。离线 OCR 不收费，但不能可靠还原复杂公式和图像，不适合直接作为精确出题依据；理工科教材推荐保留原页并人工核对。大批次识图可能产生明显费用，1000 页是上限而非性能保证。
