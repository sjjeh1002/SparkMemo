# SparkMemo 智能记忆学习助手

> 本地优先 · FSRS-5 间隔重复 · AI 全链路 · Windows + Android 双平台

把「笔记 → 卡片 → 复习 → 反思」整合为完整学习闭环的智能记忆应用:
笔记一键转卡片,FSRS-5 科学调度复习,AI 自动生成反思与计划。所有数据保存在本地,无需注册账号,无广告。

## ✨ 核心特性

- 🧠 **FSRS-5 间隔重复算法** — 比传统 SM-2 更精确,期望记忆保持率可调,每日新卡上限 1–99999999 任意设置
- 🤖 **AI 全链路(可选配置)** — AI 制卡 / AI 出题 / AI 反思 / AI 计划 / AI 助手 / AI 定制
- 🔓 **模型自由,零订阅** — 兼容 DeepSeek / OpenAI / Kimi / GLM / Claude / Ollama(本地),按实际 API 调用计费
- 📚 **学习不设上限** — AI 制卡/出题数量由内容决定(多轮并行 + 失败自动重试),超大文档自动分块不超上下文
- 🏠 **本地优先** — 无账号、无广告、无数据画像,支持 .db 完整备份与恢复
- 📱 **双平台一致体验** — Windows 绿色免安装 + Android APK,局域网增量同步(含冲突处理)

**Windows**
1. 解压 `SparkMemo-Windows-x64-v2.0.0.zip` 到任意目录
2. 双击 `smart_study.exe` 即可运行(无需安装)

**Android**
1. 安装 `SparkMemo-Android-v2.0.0.apk`(如提示「未知来源」,请在系统设置中允许本次安装)
2. 如与旧版本冲突,请先卸载旧版再安装

**配置 AI(可选,强烈推荐)**

## 🔒 安全加固(正式版)

- **Release AOT 编译** — 安装包内不含任何 .dart 源码
- **Dart 符号混淆**(`--obfuscate`)+ **Android R8 混淆** — 类名/函数名/变量名不可读
- **ELF 调试信息剥离**(DWARF)+ **构建路径脱敏** — 不泄露本机用户/目录信息
- **符号表仅本地保留** — 用于故障堆栈还原,不随安装包分发

- 仅供学习交流使用
