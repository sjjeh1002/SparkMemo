# SparkMemo 智能记忆学习助手

> 本地优先 · FSRS-6 · 理工科智能学习 · Android

把「笔记 → 卡片 → 作答 → 复习 → 反思」连接成学习闭环。学习数据保存在本机 SQLite，无需注册 SparkMemo 账号，无广告。基础学习功能可离线使用；使用云端 AI 时，相关内容会发送给所配置的服务。

## 加固与限制

公开版采用 Release AOT、Dart 混淆；Android 额外执行 R8、原生库符号剥离、FixApk（arsc/lib STORED+CRC）、16KB zipalign 和 v2/v3 签名校验。调试符号仅留本机。

这些处理不等于不可逆安全保证或商业加壳。开放题 AI 判断可能出错；不含代码执行沙箱或 FSRS 权重训练器；高阶变式依赖 AI/已有题库。知识点掌握度及作答历史目前不跨设备合并。不同版本可能使用同一数据库，降级前需要兼容备份。

## 快速使用

1. 在“更多 → 备份与恢复”保存完整备份后，覆盖安装 Android 公开版 APK。
2. 在学习页体验独立离线示例，或到“笔记 → 导入资料”添加教材、文档或照片。
3. 简答及开放解答需要 AI：在“更多 → 设置”配置出题 / 判题模型。识图可跟随已有 DeepSeek 或使用独立接口，按页面提示核对可用模型；独立设置仍保留。客观卡可本地评分。
4. 在学习页开始作答，到期卡可分轮继续；正常每日新卡上限保留。客观卡需要传统翻卡评分时可开启手动 FSRS。
5. 在“更多 → 打卡与学习报告”记录实际学习与备注；助手可新建、切换、改名并手动清理对话。输入框旁的附件按钮可选择已有笔记，或“导入新笔记（文档/PDF/图片）”，完成识别后返回并选择正文。批量工具与网页复制导入每批最多1000张、200000字符，超限请分批；网页制卡提示词单次请求仍最多100张。成功入库后卡片与目录立即刷新。常见问题见“更多 → 新手指南”。
6. 定期保存完整备份。`.sparkmemo` 包没有加密，包含本机保存的 AI 配置与密钥，不要公开分享。若手机保存为 `.bin`，仍可在恢复时选择，应用依据内容校验。

### 图片与扫描教材导入

在「笔记」点击唯一的「导入资料」主按钮，再选择「照片 / 图片」或「文档 / PDF」，可一次多选 PNG/JPEG/WebP 或 PDF；每批最多 1000 页，单图 20 MB、PDF 500 MB。先在本地保存原页，可暂停、重新选原文件续导，不会重复保存成功页。在设置中确认可用识图来源后，点击识别并确认发送；逐页核对公式、文字和图像，再创建笔记。

在统一入口选择文档 PDF 后，可选「保留图片 / 识图导入」或「仅文字（离线）」。离线 OCR 不收费，但不能可靠还原复杂公式和图像，不适合直接作为精确出题依据；理工科教材推荐保留原页并人工核对。大批次识图可能产生明显费用，1000 页是上限而非性能保证。

历史版本与更新说明见 [Releases](https://github.com/sjjeh1002/SparkMemo/releases)。第三方字体和依赖保留各自许可证。
