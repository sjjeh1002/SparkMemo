# Android 开发与验收范围

2026-10-08 起按用户决定保留 Flutter / Dart，集中开发、测试和发布 Android。新功能及修复以 Android 为验收目标，不再构建或发布新的 Windows 运行包。

- Android 公开版：Release AOT、Dart 混淆、R8、原生库符号剥离、FixApk、16KB 对齐与签名校验；在保留用户数据的前提下真机覆盖安装。
- Android 开发版：对应源码、测试、脚本与未混淆 APK，仅保存在本地及上传前核验为 PRIVATE 的开发仓库。
- Windows 平台目录、兼容代码、既有安装及历史下载保留作历史资料，不删除用户学习数据。历史 Windows 成功记录不替代本版 Android 验收。
- 构建脚本默认并仅接受 Android（`a`）；打包脚本只输出 Android APK。构建主机仍可使用 Windows，这与应用的目标平台不同。

## 后续开发顺序

优先修复实际 Android 故障：AI 制卡的请求容量、有限重试、逐卡保留、暂停与续跑；大 PDF 的逐页处理和内存占用；其次改进页面交互。依据代码、运行记录及真机结果判断问题，不因语言猜测重写整套软件。

每次修复运行相关回归，发布前运行全量 Flutter 测试与静态检查，构建后核对 APK 版本、归档完整性、签名、对齐及真机结果。自动测试使用固定模型响应；真实云端响应另行验证，不能用测试通过保证所有模型永不报错。

当前 SQLite 结构仍为 v10。暂停保留草稿，续跑优先跳过已经确认的知识点；模型截断抢救的卡片须核对通过后才计为完整覆盖。导入语、过渡语、阅读提示和章节安排不应单独生成卡片；包含定义、公式或条件的段落不能仅因同时有引导句而整段删除。
