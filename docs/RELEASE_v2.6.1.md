# SparkMemo v2.6.1 公开版（预发布）

Windows x64 / Android，构建号 23。只发布加固运行程序，不包含应用源码、个人数据库、API Key、登录凭据或调试符号。源码和未加固开发版仅上传 PRIVATE 开发仓库。

## 修复与功能

- Android 大 PDF 导入：移除界面 isolate 上的 Syncfusion 整本同步解析，优先文件路径交给 pdfium 后台逐页处理；离线 OCR 单页有界渲染，页结束即释放图片。支持最多 1000 页、500 MB，显示进度，可在当前页结束后取消，不保存残缺笔记。
- 修正「图片 / PDF 识图导入」入口放错到删除弹窗的问题，现在在笔记首页直接可见。一次多选 PNG/JPEG/WebP/PDF；普通 PDF 入口也可选保留原页图片或仅离线文字。识图 API 发送前单独确认，不自动收费调用。
- 长笔记列表只读取摘要，打开正文时分块读取；长正文分屏渲染，原始内容与制卡输入不截断。
- 大图片 BLOB 分块读取，规避 Android CursorWindow 单行容量限制；修复图像创建异常时未释放 PDF render 的路径。
- 延续生成核心流式续跑、独立识图/出题模型、原图配题、手写照片作答。识图只做转录，出题模型负责纠错、可靠补条件和推理；歧义需人工核对。

## 验证状态

- 596 项全量测试通过、5 个手动门控测试默认跳过。新增 300 页普通 PDF 路径、取消/重导、事件循环响应、大正文/3 MB 图片无损读取、原文分页、笔记主入口回归。
- 静态检查 0 error、11 warning、205 info，不宣称 lint 全绿。
- Windows / Android 公开版和开发版均已构建；公开 APK 使用 FixApk、16KB zipalign、v2/v3 签名，CRC/原生库布局检查通过。
- Android 16 真机隔离回归：438 页、约 24 MB 扫描教材，离线 OCR 全部完成（276123 字符），先取消再重导通过；UI 心跳最大间隔 207ms。原页图片保存 438 页、暂停续导、重选去重、SQLite 图片读取通过，UI 心跳最大间隔 122ms。两轮无新增 ANR。测试使用同一导入实现，不读取用户数据库，不发送教材到云端。
- 最终加固公开 APK 已在 Android 16 真机覆盖安装为 2.6.1+23，冷启动通过（787ms）；旧笔记列表可读，「图片 / PDF 识图导入」及批量选择入口可用，无新增崩溃/ANR。未清空原应用数据。完整 438 页测试在隔离回归程序中使用相同导入实现执行，不冒称在最终加固包中再次跑完全部页面。
- 本次数据库结构仍为 v10，无删除或迁移旧笔记/卡片/学习记录。来自更早版本仍由原有加法迁移升级。

## 限制

离线 OCR 仅为文字提取，复杂数学、表格与函数图不保证准确；理工科笔记推荐原页识图后核对。1000 页是单批上限，不是所有机型的性能保证。云端识图可能产生费用，本次大型教材回归不向外部 API 发送内容。媒体跨设备需完整数据库备份，现有部分同步不包含媒体 BLOB。APK 沿用 debug 签名，仅作预发布测试；加固不等于不可逆或商业加壳。
