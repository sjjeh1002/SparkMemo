# SparkMemo v2.6.6 — Android 阅读与 AI 作答

2026-10-10，2.6.6+28，Android 预发布；SQLite v10，沿用签名覆盖安装。

## 使用变化

- 中文字体改为完整字库的标准 400 / 600 静态字重，统一字号、行距、标题、卡片、输入框及浅色/深色主题。保留系统无障碍字体缩放，再叠加应用内字体偏好。
- 底部保留学习、笔记、卡片、助手四个常用入口，反思、统计、设置放入「更多」。保留原页面导航和数据刷新。
- 数学与中文保持同段自然换行，支持行内/块公式、常用裸 TeX 与二次转义；长块公式可横向滚动。代码、金额、路径、链接仍按原含义显示，未知命令安全保留原文。
- 数学输入加入分式、平方、根式、积分快捷键与有界预览；修复极小分页预算下 emoji 可能导致无限循环。
- 学习题干、反馈、笔记摘要、卡片预览和助手回答使用统一内容渲染。笔记摘要可折叠、复制、编辑；制卡主入口可见，网页制卡放入其他方式。目录按文件夹层次展示，兼容窄屏和大字体。
- 助手支持复制，工具响应折叠；修复同一用户消息被重复加入模型历史的问题。
- 所有简答、旧基础文字卡和开放解答均实际调用独立出题/判题模型，包括与参考答案完全一致的作答；接受等价措辞、不同合理解法及无唯一字符串答案的题目。客观题保留可验证的本地判定。
- API 未配置、请求/解析失败、低置信度、条件不足或识别待核对时保留答案和重试入口，不写 FSRS、掌握度或作答评分记录。高级翻卡自评也不能绕过主观题 AI 判题。
- 拍照作答只提取学生手写，排除印刷题干、标准答案、页面背景与界面文字，不补全学生未写的解法。无手写或不确定时阻止直接确认；识别后必须人工核对，可保留选中部分、清空或重拍。「重拍 / 换图」明确选择拍照或上传，取消保留当前照片及核对结果。旧照片 JSON / 图像描述不进入判题。
- 制卡与变式按材料选择填空、判断、选择、计算、推理等合适题型，参考近期题型减少单一短答；显式题型限制和真题原样要求优先。形态不符只修失败卡，同批合格卡保留。
- 修复知识卡已齐但连续导入语缺少证据导致草稿永不完成的问题。严格本地规则只排除逐句均可确认的纯导入提示，保存完整原文、原因与「本地逐句规则」来源；未知句、定义、公式或知识混合段仍显示缺口并补齐。旧草稿可保留已有卡续跑，不把导入语制成卡，不重做已生成的合格卡。
- 删除自建卡组同时移除持久化定义，修复刷新后重新出现；已删来源卡且无学习历史的知识点退出当前列表，保留共享活卡、独立知识点和历史数据。
- 修复 AI 配置读取失败后空表单覆盖原设置、AI 定制退出后更新已销毁页面、照片退出/失效后继续发起请求等实际问题；识图连接测试可停止。
