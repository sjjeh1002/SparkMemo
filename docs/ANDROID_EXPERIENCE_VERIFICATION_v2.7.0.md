# SparkMemo v2.7.0 Android 体验与数据验证记录

版本 2.7.0+30；SQLite v11。以下按实际代码与回归范围记录本轮 15 项需求，并单列最终公开包的 Android 虚拟机验收。发布汇总由准备脚本读取 `release-facts-v270.json` 填入；虚拟机结果与物理手机结果分别记录，不互相替代。

## 本轮变化与使用方式

1. **图标与启动页。** 新增 SparkMemo 原创图标、Android 各密度图标、adaptive / monochrome 图标及浅色 / 深色启动资源；启动页与应用中的品牌图形保持一致。桌面启动器如何显示 monochrome 图标由系统和启动器决定。
2. **阅读与界面。** 统一中性背景、主题层次、字体字重、标题与正文间距；常用底部入口为学习、笔记、卡片、助手和更多。数学内容沿用可显示公式的 Markdown 组件，长公式横向查看。反思、统计、设置、助手管理等窄屏操作改为可换行或可滚动布局；系统字号与应用字号叠加生效。
3. **回收站批量管理。** 卡片普通删除移入回收站并保留学习记录，可多选恢复或永久删除，也可清空全库回收站。永久删除确认框显示实际数量，并明确连同作答、复习记录一起删除、不可恢复。全库清空不受当前文件夹或搜索过滤影响；取消不改变数据。
4. **资料导入单入口。** 笔记页只保留一个“导入资料”主按钮，先选择文档 / PDF 或照片 / 图片。PDF 可选择保留原页识图，或离线文字提取 / OCR；发送识图服务前仍需确认。取消选择不启动导入或修改笔记。
5. **按钮含义。** 主入口和操作提示使用“导入资料”“新建对话”“恢复卡片”“永久删除”等直接描述；学习完成显示“本轮完成”，不把一次批次完成误称为全天没有到期任务。已有暂停、取消、复制、核对与目录选择语义保留。
6. **操作习惯。** 文件夹点击先打开，通过路径、上一级和系统返回导航；移动时明确选择目标目录，取消保留归属。更多中集中放置打卡、反思、统计、设置、备份和指南；备份恢复期间阻止新操作，恢复后重建页面，直接读取恢复后的数据。
7. **独立示例练习。** 内置 16 道离线题使用独立的 `demo_training_sandbox.db`，不创建个人卡片、文件夹、复习成绩、打卡或统计数据，也不复制个人 AI 密钥。旧版污染的示例仅在完整题组、内容、关联和历史证据均能精确确认时迁移：先在沙盒归档完整原记录，再从个人库隔离。用户同名、同标签、内容相似、移入自己文件夹、编辑过或不完整的记录不删除；无法确认时保留，在默认折叠的示例课程里以普通说明提示手动核对，不再当作学习页面红色错误。真正归档失败仍显示安全的故障原因与重试入口，保留原记录，不阻止应用启动。
8. **首周与复习调度。** 核查没有发现“前 7 天人为减少到期复习”的策略，因此本版没有宣称取消一个不存在的规则。FSRS 公式、旧卡状态和到期时间保持原算法；全部到期复习不受用户新卡上限约束。单轮题数仍是界面批次大小，可以继续下一轮；正常每日新卡上限保留。
9. **打卡与每日报告。** “更多 → 打卡与学习报告”显示每日实际复习次数、不同卡片数、新卡数、记录的作答时长和近期日期列表；可手动打卡、补充备注和选日查看。完成学习后记录当天打卡。AI 仅基于当天汇总证据及用户备注生成报告和鼓励，不编造成绩、排名或掌握度；报告按日保存，启动和当天打卡的自动尝试次数有上限，失败可手动重试。未配置 AI、请求失败或取消时显示诚实的本地反馈与配置提示，不把它标成 AI 生成。时长来自已有作答 / 复习记录，不是全天专注计时；未判定的答案不会被计成正确或错误。
10. **通俗指南。** 更多中新增“新手指南”，包括首次使用步骤和 12 组常见问题，说明导入、AI 配置、制卡、文件夹、照片核对、打卡、助手、示例、备份和删除，可直接跳转导入、学习或设置。
11. **助手多会话。** 助手可新建、切换、改名和管理相互独立的对话；正文、工具执行历史、输入草稿和附件快照保存在本机。手动清空当前 / 全部对话会明确确认，保留已创建的卡片、笔记、文件夹和学习记录。文件夹工具支持创建、改名、移动和删除容器，助手按用户明确指令执行，先查询真实 ID、依据工具实际返回报告结果；不是每次操作另弹确认框。移动失败事务回滚，删除容器保留卡片与子文件夹；请求时应明确文件夹和目标位置。
12. **完整备份与恢复。** 在设置中保存 `.sparkmemo` 包，包含完整个人数据库及存在的自定义背景图片：卡片与 FSRS、文件夹、笔记与数据库中的原页图片、生成草稿、作答 / 复习、计划 / 反思、打卡、助手会话 / 草稿和设置均随数据库保存。已保存的 AI 配置和密钥也在其中；备份包没有加密，应只保存在本人信任的位置，不作为公开发布文件。兼容旧版 `.db`，但单独数据库没有可移植的外部背景图。部分 Android 文件提供器会把导出的 `.sparkmemo` 改为 `.bin`；恢复允许选择这种文件，依据备份结构、校验和数据库内容判断有效性，不因后缀变化排除，也不因后缀相同跳过校验。恢复先校验、升级临时副本并显示资料数量，确认后自动留下恢复前完整安全备份；失败回滚原库，成功无需重启。独立示例沙盒不属于个人备份；原教材外部文件、临时缓存、系统授权和未保存的请求结果不承诺还原。
13. **附件入口与识别正文。** 助手输入框旁的附件按钮可选择已有笔记，也可直接点“导入新笔记（文档/PDF/图片）”，复用笔记页统一导入流程；完成提取 / 识图后返回助手，重新选择笔记附加，保留原对话草稿。修复该入口独立笔记页的透明黑底：独立笔记与指南绘制浅深主题底色，HomeShell 内嵌页继续保留自定义背景；指南功能入口返回根页面再切换目的页，后台助手不会重新弹出附件列表覆盖目的页，正常返回助手仍可选择笔记。附件读取已提取 / 识图后的文字正文，不用图片 JSON、文件路径或摘要冒充原文；没有有效正文的笔记拒绝附加。只识别部分页会标明不完整，超过 24,000 字符会明确提示只发送前段；本功能不会自动重新识别未完成的资料，也不代表助手已读取整本教材。
14. **大量导入与立即刷新。** 助手新增实际可调用的 `add_cards` 批量工具，网页复制导入也支持每批 1–1000 张、完整 JSON 最多 200000 字符；超限明确提示分批，不截断卡片或只导入有效前缀。网页制卡提示词的单次请求数量仍为 1–100 张，这是请求数量限制，不是导入上限。整批先校验再原子入库，非法卡片、数据库失败或网页导入中途取消全批回滚，不改旧卡的 FSRS、标签与历史；相同题目加答案按真实数量跳过。成功提交且有新增时通知一次 DataBus，卡片页和目录数量立即读取完整结果，文件夹页忙碌期间保留待刷新通知，解除忙碌后补读；失败不发送成功更新。回复失败后续跑保留真实工具上下文，不自动重复已经提交的制卡或文件夹操作；执行结果无法确认时先提示核对。导入全程注册后台任务，恢复不能关闭正在使用的数据库，旧页面和排队草稿不会跨数据库代次继续访问旧连接。
15. **整合修复。** 回归覆盖恢复时的数据库替换锁、旧页面写入、后台 AI 生命周期、助手取消 / 续跑、导入退出、回收站事务、旧版数据库升级、示例归档失败和小屏大字号。后台学习总结与每日 AI 报告全程注册任务，恢复前等待任务完成或取消，避免关闭数据库后旧请求继续写入。补齐制卡草稿读取失败后解除加载并手动重读、恢复媒体尺寸异常时按真实图片尺寸显示、识图初始化及已保存正文读取失败时显示安全错误与重试入口；不删除、迁移或重写原笔记和原图。测试范围与最终结果见下文，不承诺软件或模型从此没有错误。
