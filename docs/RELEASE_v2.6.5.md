# SparkMemo v2.6.5 — Android 制卡优化

2026-10-08，版本 2.6.5+27，Android 公开预发布；SQLite 保持 v10，无数据库结构迁移。

## 平台范围

按用户决定保留 Flutter / Dart，集中开发和验收 Android。从本版起只发布 Android APK，停止新增 Windows 运行包；历史 Windows 下载及源码兼容目录保留。此前 2.6.4 为本地测试候选，未上传 GitHub，其修复纳入本版。见 [Android 支持范围](ANDROID_SUPPORT.md)。

## 修改

- 正常出卡批次从 3 个知识点增加到 6 个，单次最多 6 张；补缺批次最多 3 个，保留原文证据、题型、质量与数量校验。
- 输出提示改用必要字段，辅助训练字段只在需要时输出，减少空字段及无关元数据。
- 完整 JSON 按卡片逐一校验，通过的卡片立即保留；同批坏卡不再使合格卡反复重做。后续只补失败项，并显示字段级原因。
- 修复截断抢救结果被后续部分有效响应误算为完整覆盖的问题；待确认状态可保存和恢复，只认可当次验证通过的题干。
- 已有卡有效覆盖新的知识点也计为进展，避免任务过早停止。持续无进展时有限停止，保留错误和草稿供续跑。
- 运行中显示已保存卡片数及当前阶段，新增可复制的制卡运行记录，包括请求耗时、状态和错误代码，不含正文、答案、密钥或请求头。
- 保留低价值纯导入语、过渡语、阅读提示和章节安排过滤。含实际定义、公式或条件的段落仍参与制卡。
- 保留请求中断与草稿续跑、大 PDF 逐页识别、助手消息复制和文件夹分类界面。
- 公开与开发构建、打包脚本仅接受 Android，并校验待打包 APK 的版本，防止旧包被标成新版本。

## 验证与边界

- 全量 627 项测试通过，5 项手动门控默认跳过。静态检查 0 error / 11 warning / 223 info；存在历史提示，分析命令因提示返回非零，不将其写成完全通过。
- 固定响应测试：12 个短知识点需 2 次出卡请求（原为 4 次），另有 1 次知识清单请求；坏卡只补失败项。这是自动测试，不代表真实网络一定加速一倍。
- 两项新增回归先在旧实现失败，修复后通过：截断结果不会误算完成；共享卡映射不会触发过早停止。效率及可靠性针对性测试共 19 项通过。
- 2026-10-08，Android 16 真机最终公开 APK 覆盖安装并冷启动成功（versionCode 27）；原学习数据及 175 张历史草稿保留。12 个数学定义生成 12 张卡片，两段导入/阅读提示未制卡；两次真实 deepseek-flash 出卡请求均 HTTP 200，无格式错误、无重试，耗时分别 8.824 秒和 8.900 秒。安全暂停在约 2.8 秒内观察到已暂停界面，随后续跑完成。验收草稿未导入学习卡库，仅删除本次自建验收笔记。
- Android 公开版与开发版完成构建；公开 APK 归档完整性、原生库与 arsc 的 STORED/CRC、16KB 对齐、v2/v3 签名通过校验。手机验收使用最终加固公开 APK；开发 APK 仅构建验收，未安装手机。
- 历史长笔记在升级前已生成 175 张，分段显示完整覆盖；21 条保留运行记录中 20 条成功，1 条曾因选择题缺少选项而失败，后续恢复完成。这属于此前 2.6.4 本地候选的历史结果，不冒充本版新增云端性能测试或零错误记录。
- 模型与网络仍影响耗时及生成质量。未通过格式、来源或质量校验的内容不会算作完成；知识覆盖及识别文字、公式仍需核对。本版不宣称整本教材或全部机型已验证。

## 分发

公开版只发布加固 APK、校验文件和说明。源码、测试、脚本及未混淆开发 APK 仅上传经核验为 PRIVATE 的开发仓库。沿用项目预发布签名，覆盖安装保留数据，不以卸载或清空数据解决安装问题。
