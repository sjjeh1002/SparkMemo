# SparkMemo v2.6.7 — 文件夹整理与完整卡片库

2026-10-10，2.6.7+29，Android 预发布；SQLite v10，沿用签名覆盖安装。

## 修复与使用变化

- 文件夹与标签模式都完整读取当前筛选的卡片，不再限制首批 100 张或要求点击下一页。列表仍只绘制可见行，搜索、全选、移动和导出针对完整结果。
- 点击文件夹先打开；通过路径、上一级和系统返回导航。在移动弹窗明确确认“选择此文件夹”，根目录表示未分类；取消不修改归属。可在选择目标时新建子文件夹。
- 单张卡片菜单支持移动；选择卡片后底部固定显示移动和批量操作。移动成功报告实际数量，并可直接查看目标。批量移动先固定选择快照，在同一事务校验和保存；失败不产生部分移动。
- 移动成功提示位于批量工具栏上方，并增加关闭按钮；提示显示期间可继续操作，不再遮住底部按钮。
- 当前文件夹新建卡片默认保存于此，编辑显示文件夹真实路径。保存时重读卡片，保留期间新增的复习记录；已删除卡片不会被旧编辑弹窗复活。目标被删除或归档后拒绝保存并回滚。
- 文件夹移动防止自包含或循环；删除只移除容器，把卡片和子文件夹移至上级，保留学习历史。孤儿目录、循环关系与失效卡片归属可恢复到根，更新同步时间。
- 冻结与回收站按当前状态计算数量；回收站卡片先恢复再移动。归档祖先不可作为移动目标，恢复时先恢复上级。兼容旧卡 deleted 为 NULL 的显示、计数与到期处理。
- 标签批量整理和删除也固定选择快照、原子执行并保护页面退出；删除文案与实际回收站/保留历史行为一致。

学习每日队列额度不变；原有 AI 判题、拍照手写核对、数学排版和制卡策略保留。本版不进行数据库结构迁移或清除用户数据。
