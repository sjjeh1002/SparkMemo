## 实现与回归边界

- 网页制卡页面及入口、两个旧页面测试和服务预设模块已移除。助手仍通过原生批量工具创建卡片；共享的 JSON 导入解析器继续使用。原有卡片、会话、草稿和学习记录不删除。
- 官方 ChatGPT 登录通过系统浏览器、随机 127.0.0.1 回调、PKCE、state、nonce 和已签名身份校验激活账号；身份登录与套餐推理权限分开处理。不读取其他应用的登录文件。
- Mock 协议测试覆盖多账号、真实 RS256/JWKS 正反例、刷新单飞与轮换、晚到退出、写盘期间取消、额度、断流、完整结束事件和工具调用。模型目录保留服务端顺序及名称，用户显式选择模型和用途；这些测试不等于真实用户账户的端到端授权。
- 助手工具在异步保存后和每次执行前检查账号代次，切换账号后停止尚未执行的操作；已提交的操作结果仍保存。临时 reasoning 项仅同账号同次执行内使用，不进入历史序列化或备份。
- 制卡引擎单独验证 OAuth Responses 路径，禁止失败请求被外层超时或网络重试重复发送。完整模型输出后的有限格式修复保留。独立图像生成仍使用原有 API 配置，不声称该登录方式支持官方未开放的图像生成工具。
- 三页合成资料验证 HTTP 429、SSE 额度失败和身份权限不足：仅当前页失败，其余页保持待处理；恢复后完成余页，再次续跑不重复请求成功页。图片转录保留数学原式，印刷或空白内容不作为本人作答。
- 统一模型与识图设置相互刷新，关闭 ChatGPT 识图并保存后恢复此前来源。原有 API 地址、型号与密钥保留；切换服务时留空密钥不会带入前一服务的密钥。
- 卡片批量操作跨越数据库恢复后拒绝旧确认结果。长标签合并弹窗、小屏与两倍字号、模型列表、设置、键盘和助手附件均有布局回归。

## 原生存储验证

在独立包 `com.smartstudy.smart_study.authprobe` 运行与最终应用相同的 Kotlin 存储代码。探针 UID 10217，主应用 UID 10216，未使用主应用数据库或真实凭据。

84,992 UTF-8 字节的长中文 fixture 精确往返；同一明文重写后 IV 与密文均变化；进程重启后精确读回、写入次数为 0，密文不变。加密文件位于 `no_backup/chatgpt_credentials.v1.enc`，扫描探针私有文件未发现 fixture 明文或 SQLite 数据库。探针 APK 不属于发布资产。

普通 `.sparkmemo` / `.bin` 备份包含原有 API 配置及密钥，应私密保管；ChatGPT OAuth 登录文件和设备密钥不进入普通备份，换设备后需重新授权。

## 设备与真实服务限制

所有 ADB 操作固定独立 `SparkMemo_API36 / emulator-5554`，未操作物理手机或复制用户资料。原有合成库包含 1000 张卡片、2 篇笔记、3 条复习记录、3 条作答记录和 8 条助手消息。

本机无凭据读取 OpenAI 官方 OIDC discovery 成功，端点与实现一致。虚拟机首次启动 Chrome 时连接曾中断，随后冷启动原 AVD，数据完整性和安装包校验正常；未据此认定应用崩溃原因。曾遇到连接失败，后续最终公开包成功启动系统 Chrome 并显示 `auth.openai.com/log-in` 官方登录表单，返回应用取消后提示“操作已取消，已保存的设置未更改”。没有输入或读取用户密码。本轮没有完成真实用户 ChatGPT 授权、模型目录读取或套餐推理，不能把登录表单、Mock 和原生存储探针记作真实账户调用。

可用账号、套餐、应用资格和模型以 OpenAI 服务端实际授权为准。参考 [官方登录流程](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[模型与推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference) 和 [预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。本版没有重新进行豆包与 DeepSeek 图片排名比较，也不改动用户已明确选择的识图来源。

发布校验包括各版 APK 签名、版本与哈希、公开包符号剥离和凭据模式扫描，以及构建 stage 与冻结源码核对。规则扫描通过不代替全部设备、真实手写、厂商文件提供器、网络环境或服务账号验收。
