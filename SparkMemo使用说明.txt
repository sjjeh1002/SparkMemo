【一、软件简介】
SparkMemo 是一款本地优先的智能记忆学习应用，把「学习卡片 + FSRS-5
间隔重复算法 + AI 全链路」整合为一个完整学习闭环：
  笔记 → AI 自动生成卡片 → 科学复习 → AI 反思与计划
所有数据保存在本地，无需注册账号，无广告，无云端强制依赖。

【二、安装】
■ Windows 版
  1. 解压 SparkMemo-Windows-x64-v2.0.0.zip 到任意目录（建议英文路径）。
  2. 双击 SparkMemo.exe 即可运行，绿色免安装。
  3. 卸载：删除整个文件夹即可；数据见「五、数据与备份」。
■ Android 版
  1. 安装 SparkMemo-Android-v2.0.0.apk。
  2. 如提示「未知来源」，请在系统设置中允许本次安装。
  3. 卸载前请先导出备份（见「五」），卸载会清除应用私有数据。

【三、首次使用：配置 AI（推荐，可选）】
不配置 AI 也能完整使用卡片、复习、统计等本地功能；
AI 功能（制卡 / 出题 / 反思 / 计划 / 助手 / 定制）需要先配置模型：
  设置 → AI 模型配置 → 快速选择供应商（DeepSeek / OpenAI / Kimi /
  GLM / Claude / Ollama 本地 / 自定义）→ 填入 API Key → 保存配置
  → 测试连接
  · 推荐 DeepSeek（开放平台免费额度多、便宜、中文好）。
  · 画图模型（可选）：AI 定制生成背景图时使用，可用免费 Pollinations。

【四、主要功能】
■ AI 助手（底部第 1 页）
  · v2.0.0 起为 DSH 风格 agent（借鉴 DeepSeek Harness 开源架构）：原生工具调用多轮循环，
    AI 可真正操作软件本身——
    - 卡片：添加 / 按标签·关键词查询
    - 设置：读取 / 修改（保持率 / 新卡上限 / 主题色 / 深色模式 / 鼓励语）
    - 统计与计划：学习统计 / 今日计划
    - 笔记：创建 / 查询
    - 导航：直接跳转任意页面
  · 工具执行过程实时展示；失败明确说明；建议使用支持 function calling 的模型（DeepSeek/OpenAI/Kimi/GLM）
■ 复习（第 2 页）
  · 翻卡 → 四档评分（忘记 / 困难 / 模糊 / 轻松）→ FSRS-5 自动调度
  · 每日新卡上限可自定义：滑块 5-1000，输入框 1-99999999（留空 = 不限）
  · 今日计划：复习目标 / 新卡目标 / 时长；可让 AI 自动调整本周计划
  · 复习结束后可自动生成今日反思草稿
■ 卡片库（第 3 页）
  · 添加 / 编辑 / 删除卡片，搜索、按标签筛选
  · 卡组管理：重命名 / 合并 / 删除标签，批量移动 / 追加 / 删除
  · 导出 Excel / PDF
■ 笔记（第 4 页）
  · 导入 md / txt / csv / docx / pptx / xlsx / pdf
  · AI 总结（摘要 + 知识点 + 术语表）
  · AI 生成卡片：按内容量自动决定卡数（多轮并行、失败自动重试），
    导入时可选「已有卡片组」或「新建卡片组」
■ 反思（第 5 页）
  · 每日反思记录（学了什么 / 困难 / 专注度 / 情绪 / 时长）
  · AI 反思草稿：基础模式（本地统计）/ 专业模式（AI 分析）
  · 周度 AI 学习分析（结果自动保存）
■ 统计（第 6 页）
  · 复习量柱状图（周 / 月 / 年）、连击、稳定性分布、FSRS 遗忘曲线
  · 成就系统（首次复习 / 连续打卡 / 卡片数 / 稳定性等）
■ 练习（卡片库右上角「练习」进入）
  · AI 出题：单选 / 多选 / 填空 / 简答，数量自定义（1-9999999）或 AI 自决
  · 答题四档评分，可导出题卷、一键「设为卡片」
■ 局域网同步（设置 → 局域网同步）
  · 同一 WiFi 下设备发现，增量双向同步，基于时间戳的冲突处理
■ 插件系统（设置 → 插件系统）
  · 事件钩子（建卡 / 复习 / 同步 / 计划等）调用本地脚本（如 Python）
■ AI 定制（设置 → AI 定制）
  · 用自然语言定制：主题色 / 新卡上限 / 字体 / 深色模式 / 鼓励语 / 背景图

【五、数据与备份】
· 数据位置（Windows）：%APPDATA%\com.smartstudy\smart_study\
· 数据位置（Android）：应用私有目录（需 root 或备份工具访问）
· 强烈建议定期：设置 → 导出数据备份（.db 文件），可随时从备份恢复
· 换机迁移：旧机导出 .db → 新机安装后 设置 → 从备份恢复

【六、常见问题】
Q: AI 调用失败 / 超时？
A: 检查 设置 → AI 模型配置 的 Base URL / API Key / 模型名，点「测试连接」；
   网络慢可换更快的模型或服务商；本地 Ollama 无需 Key。
Q: 复习页没有卡片？
A: 新卡上限设为 0 不会出新卡；到期卡未到复习日；检查卡组筛选是否误选。
Q: 局域网同步找不到设备？
A: 两台设备需同一 WiFi；对端需打开同步页；防火墙放行 8765 端口；
   也可手动输入对端 IP 连接。
Q: 插件不执行？
A: 需本机装有脚本运行环境（如 Python）；事件发生时才会触发；可在插件页删除重建。
Q: Android 导出 PDF 中文乱码？
A: 个别机型缺少中文字体所致，Excel 导出不受影响。
Q: 忘记 AI Key 会不会丢数据？
A: 不会。AI 只读数据生成内容，学习数据始终在本地。
